```python
class UsdctoFiatToolkit(BaseToolkit):
```

USDCtoFiat toolkit for CAMEL agents by Galleon Labs.

Built on the public Peer/ZKP2P protocol.
Docs: https://usdctofiat.xyz/developers

**Parameters:**

- **signer** (Callable, optional): Callback `(unsigned_tx) -> hash | {hash, deposit_id}`. Kept in the host runtime. Never a private key. (default: :obj:`None`)
- **timeout** (float, optional): Optional per-call timeout forwarded to BaseToolkit. (default: :obj:`None`)

### usdctofiat_cashout

```python
def usdctofiat_cashout(self, mode: str, amount: str, currency: str, platform: str, payee: str):
```

Cash out Base USDC to fiat via USDCtoFiat by Galleon Labs.

mode is required. There is no default.

- fast: Live market pricing with 0% spread / 0 bps.
- best: Delegate, 10 bps.

If a signer was injected, unsigned txs are submitted and the deposit id / tx hash are returned. Otherwise this returns unsigned `{to, data, value, chainId}` txs for the host to sign. Never pass a wallet private key to this toolkit.

**Parameters:**

- **mode** (str): `"fast"` or `"best"`. Required.
- **amount** (str): Human USDC amount (string or number). An int is six-decimal units.
- **currency** (str): Fiat ISO code, e.g. EUR, USD, GBP.
- **platform** (str): Payment rail, e.g. revolut, venmo, monzo.
- **payee** (str): Handle on that platform.

**Returns:**

  str: JSON string with the cash-out result or unsigned prepare payload.

**Returns:**

  str: JSON estimate payload.
